# OSI Model

The OSI (Open Systems Interconnection) model describes how data moves across a network using seven layers.

| Layer | Name | Example |
|------|----------------|------------------------|
| 7 | Application | HTTP, FTP, DNS, SMTP |
| 6 | Presentation | SSL/TLS, Encryption |
| 5 | Session | NetBIOS, RPC |
| 4 | Transport | TCP, UDP |
| 3 | Network | IP, ICMP |
| 2 | Data Link | Ethernet, MAC |
| 1 | Physical | Cables, Fiber, Wi-Fi |

---

## Layer 7 – Application

Provides services directly to end users.

Examples:

- HTTP
- HTTPS
- FTP
- DNS
- SMTP

---

## Layer 6 – Presentation

Responsible for:

- Encryption
- Compression
- Encoding

Examples:

- SSL
- TLS

---

## Layer 5 – Session

Manages communication sessions between devices.

Examples:

- RPC
- NetBIOS

---

## Layer 4 – Transport

Responsible for reliable data delivery.

Protocols:

- TCP
- UDP

---

## Layer 3 – Network

Responsible for routing packets.

Protocols:

- IPv4
- IPv6
- ICMP

Devices:

- Routers

---

## Layer 2 – Data Link

Responsible for communication on the local network.

Examples:

- Ethernet
- MAC Addresses

Devices:

- Switches

---

## Layer 1 – Physical

Transmits raw electrical, optical, or radio signals.

Examples:

- Ethernet cables
- Fiber optics
- Wireless signals

---
