# Linux Process Management

## View Running Processes

```bash
ps
ps aux
```

## Interactive Process Viewer

```bash
top
htop
```

## Search for a Process

```bash
ps aux | grep apache
```

## Kill a Process

```bash
kill PID
```

Force Kill

```bash
kill -9 PID
```

## Background Jobs

```bash
jobs
bg
fg
```

## Process Tree

```bash
pstree
```

## Check Memory Usage

```bash
free -h
```

## CPU Information

```bash
lscpu
```

## Uptime

```bash
uptime
```

## Load Average

```bash
cat /proc/loadavg
```
